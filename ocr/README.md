# OCR 验收打分工具（#120）

本目录提供 OCR 识别结果的验收打分脚本，用于回答「识别是否准确、生僻字是否不丢不假、列是否分对了」。

> 状态：v0.1（核心指标可用），后续按 #120 验收标准逐步补齐指标与边界规则。

## 本目录文件

- `score.py` — 打分脚本（CER / 列归属 / 行对齐）
- `extract_text.py` — 数字原生 PDF 文本层提取工具
- `selection-notes.md` — OCR 选型建议书（非约束性）
- `dataset-manifest.md` — 验收数据集清单（语料、排版、许可状态）

## 用法

```bash
python score.py --gold 标准答案.csv --test 待测结果.csv
```

可选参数：

- `--key 列名`：按该列值对齐两份 CSV（如 `PDF页码`）；留空则按行顺序对齐。

## 输入约定

- 两份 CSV 列结构应一致；脚本取两份共有字段进行比较。
- 待测 CSV 缺少某字段时会给出警告并跳过该字段。
- 编码：UTF-8（含 BOM 也支持）。

## 已实现指标（v0.1）

- 字级错误率 CER —— 可读字符识别错误比例；判定：逐字段做 Levenshtein 编辑距离 ÷ 标准字符数
- 字级准确率 —— 1 - CER
- 列归属准确率 —— 单元格内容与标准答案完全一致的比例；判定：逐字段字符串相等即算对
- 行对齐率 —— 待测行数 ÷ 标准行数；衡量漏切/多切（偏离 1.0 说明行边界错）

## 待补充指标（对应 #120 验收表，后续版本）

- 静默替换率：低置信字形被输出为形近常用字的次数占比（方言 OCR 头号风险）
- 生僻字覆盖：罕见字 / IPA 组合符 / 带圈序号的「正确 ∨ 合法弃权」比例
- 集外字可表示性：无法编码的字是否以约定形式（IDS/PUA）保留而非丢弃
- 合并未分离检出率：多列并成一格被标记出的召回
- 弃权质量：标为低置信的格中确实需要人工的比例

## 边界情况规则（待明确，写入指标定义）

- 空列：标准为空、待测为空 → 视为列归属正确；标准为空、待测非空 → 列归属错误。
- 跨页条目：当前按行对齐，未处理跨页拼接；后续需与「行对齐率」结合。
- 同格多符号：一个单元格含多个字符时，CER 按整格编辑距离计。
- PUA / IDS：集外字表示方案待定（见 #123），暂未纳入生僻字覆盖指标。
